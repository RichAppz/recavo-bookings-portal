## 2. New layout

- Desktop at 1100px and wider: two columns (62/38). Left: Up next, Today. Right: Needs your
  attention, Quick actions. Below: "How October is going" with the period switcher, Hide
  amounts and Customise; four headline tiles with delta and trend; Money in and Attendance side
  by side; the footnote. Narrower than 1100px the right column drops under the left.
- Phone: greeting, Up next, attention strip (opens a full-screen list), Today (last finished,
  now line, next 3, Show all), "This month ▾" + ··· (Hide amounts, Customise), 2×2 tiles with
  no trend, Money in, Attendance, Quick actions.
- The Customise order applies within each column and the performance section on desktop; the
  phone uses the spec order until the person reorders.

## 3. Data

| Need                                                     | Source                                                                       |
| -------------------------------------------------------- | ---------------------------------------------------------------------------- |
| Period figures + previous period                         | `reports/dashboard` twice (period to date; same days of the previous period) |
| Trend (12 buckets)                                       | `reports/dashboard` per bucket, desktop only, cached 5 min                   |
| Today                                                    | bookings list for today + calendar blocks                                    |
| Up next, payments to collect, attendance to mark         | bookings list two weeks back to a week ahead                                 |
| Still to collect, busiest day                            | bookings list for the calendar period (first 200)                            |
| Package requests, add-ons, waitlist, text credits, setup | existing hooks                                                               |

The dashboard counts sessions when they are booked or marked (event time), so "Still to come"
is booked − attended − no-show − cancelled, and includes finished sessions nobody has marked.

## 4. Decisions taken (spec §8)

- Greeting by first name (plain "Good morning" when the account has no name).
- Mint: the live app's `#2ee6a6` in dark mode, the spec's `#2bb985` in light.
- Period default: Month.
- Staff without `payment.read`: Money taken tile and Money in card hidden; £ dropped from value
  lines, Up next and the Today summary.
- Set-up steps shown in Needs your attention (and still in the menu).

## 5. Where the build differs from the spec

- Up next **Message** opens Messages (there is no link to one client's conversation).
- Several payments to collect, or several sessions to mark, open Bookings; the Needs action
  tab and its money / past filters have no URL yet. One of either opens that booking here.
- Customise reorders by drag or by the up/down buttons beside each card (keyboard and touch).
- Phone "Show all" opens the Calendar on its default view.
- Delta pills are hidden until the previous period has a session or a payment in it.

## 6. Needs designing

- Today event rows (staff events) between sessions: kept with an "Event" pill.
- Attention items the spec does not list: add-on requests, clients on the waitlist.
- Group session in Quick actions (kept after Add session for non-detailers).
- Last 7 days / Last 30 days / All time in a "More" menu beside Week / Month / Year.

## 7. Needs API work

- Unread client messages (conversations carry no unread state).
- Failed confirmations/reminders across the business (only per-booking history has them).
- Packages expiring in 7 days (no business-wide entitlement list).
- Page settings across devices (`/me/ui-preferences` is allow-listed), so they are per device.
- Reports links with the same period and a Calendar Day view link (no URL parameters).
- Attended rate over sessions that have ended (approximated by sessions with an outcome).
